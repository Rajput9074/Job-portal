# Job Portal API

A RESTful backend application for managing jobs, employers, and applicants.

## 🚀 Tech Stack

* Node.js
* Express.js
* MongoDB
* compass
* JWT Authentication
* bcryptjs
* Swagger UI
* Postman

## ✨ Features

* User Registration & Login
* JWT Authentication
* Role-Based Access Control
* Job Posting Management
* Job Application Management
* Protected Routes
* API Documentation with Swagger

## 📁 Project Structure

```text
src/
├── controllers/
├── models/
├── routes/
├── middleware/
├── config/
├── services/
└── app.js
```
